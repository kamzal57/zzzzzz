## Run Locally

**Prerequisites:**  Node.js (v18 or higher recommended)


1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up your Gemini API key:
   - Get your API key from [Google AI Studio](https://aistudio.google.com/apikey)
   - Copy the `.env.local` file (or create it from `.env.example`)
   - Add your API key to `.env.local`:
     ```
     VITE_GEMINI_API_KEY=your_api_key_here
     ```

3. Run the app:
   ```bash
   npm run dev
   ```
   The app will automatically open in your browser at http://localhost:3000

## Deploy

Vous pouvez déployer facilement cette app statique (Vite) sur plusieurs plateformes:

### Netlify

1. Connect your repository to Netlify
2. Configure build settings:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
   - **Environment variables:** Add `VITE_GEMINI_API_KEY` in Site settings → Environment variables

### Vercel

1. Import your project on Vercel
2. Configure settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Environment Variables:** Add `VITE_GEMINI_API_KEY` in Settings → Environment Variables

### GitHub Pages

1. Build locally:
   ```bash
   npm run build
   ```

2. Deploy the `dist` folder:
   - Option A: Use a GitHub Action to automatically build and deploy
   - Option B: Manually push the `dist` folder to a `gh-pages` branch

3. Enable GitHub Pages in repository settings:
   - Go to Settings → Pages
   - Select the `gh-pages` branch as source
   - Note: Environment variables must be set at build time. Ensure `VITE_GEMINI_API_KEY` is available during the build process.

### Other platforms

This app works on any static hosting service that supports:
- Node.js build environment
- Environment variable injection at build time
- Serving of static files from a `dist` directory

Examples: Render, Railway, Cloudflare Pages, Firebase Hosting, etc.

## Troubleshooting

**API Key Issues:**
- Make sure your `.env.local` file contains `VITE_GEMINI_API_KEY=your_key`
- Restart the dev server after adding/changing environment variables
- For production builds, ensure the API key is available at build time

**Build Issues:**
- Clear cache: `npm run clean`
- Reinstall dependencies: `rm -rf node_modules package-lock.json && npm install`
- Check Node.js version: `node --version` (should be v18+)
